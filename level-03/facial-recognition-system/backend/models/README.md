# Face Recognition Models

This directory will contain the face-api.js models needed for facial recognition.

The models will be automatically downloaded when you first run the application. The required models are:

- `ssd_mobilenetv1_model-weights_manifest.json` - Face detection model
- `ssd_mobilenetv1_model-shard1` - Face detection weights
- `face_landmark_68_model-weights_manifest.json` - Facial landmark detection
- `face_landmark_68_model-shard1` - Landmark detection weights  
- `face_recognition_model-weights_manifest.json` - Face recognition model
- `face_recognition_model-shard1` - Face recognition weights

If you need to manually download the models, you can get them from:
https://github.com/justadudewhohacks/face-api.js/tree/master/weights
