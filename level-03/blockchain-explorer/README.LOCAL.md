# Blockchain Explorer Project

This project is part of the 100 Days of Node.js challenge. It consists of a blockchain explorer and simulator that helps users understand and visualize blockchain technologies.

## Getting Started

### Prerequisites

- Node.js v16 or higher
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/AyeshaIftikhar/100-Days-of-Nodejs.git
cd 100-Days-of-Nodejs/level-03/blockchain-explorer
```

2. Install backend dependencies
```bash
cd backend
npm install
```

3. Install frontend dependencies
```bash
cd ../frontend
npm install
```

### Running the Application

1. Start the backend server
```bash
# From the backend directory
npm run dev
```

2. Start the frontend development server
```bash
# From the frontend directory
npm run dev
```

3. Access the application at http://localhost:5173

## Features

- Real-time blockchain simulation
- Block explorer with detailed information
- Transaction tracking and visualization
- Wallet/address management
- Network statistics dashboard
- Interactive mining simulation

## Tech Stack

- **Backend**: Node.js, Express, TypeScript, WebSockets
- **Frontend**: React, TypeScript, Vite, shadcn-ui, Tailwind CSS

## Project Structure

The project is divided into two main parts:

1. **Backend**: A Node.js API that provides blockchain data and simulation
2. **Frontend**: A React application that visualizes blockchain data
