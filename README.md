## 🎯 Rules

- **1 Project Per Day** (15-60 mins)
- **Document Every Project** (README + Screenshots)
- **Post Progress on Social Media** (#100daysofcode, #100daysofnodejs)

## Project Setup

- Create a folder and run the following to initialize a nodejs project

```cmd
npm init -y
```
