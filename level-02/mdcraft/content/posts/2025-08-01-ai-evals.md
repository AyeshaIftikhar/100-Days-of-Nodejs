Engineering teams often ship LLM features that **feel** good in demos but underperform in production. This guide shows a pragmatic evals loop:

1. Define user-centric metrics (quality, latency, safety).
2. Build a small-but-representative test set from real user flows.
3. Automate offline evals per PR with thresholds.
4. Track drift & regressions weekly.

```bash
# example: run evals in CI
pnpm run evals -- --threshold 0.72
