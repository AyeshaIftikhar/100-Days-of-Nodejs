# Tic-Tac-Toe WebSocket Game

[![IMAGE ALT TEXT](http://img.youtube.com/vi/cUJqEsZd0B4/0.jpg)](https://www.youtube.com/shorts/cUJqEsZd0B4)

A multiplayer Tic-Tac-Toe game using WebSocket for real-time communication.

## Features

- Real-time multiplayer gameplay using WebSocket
- Automatic matchmaking
- Rematch functionality
- Responsive UI

## Usage
1. Open the game in your browser
2. The system will automatically match you with another player
3. Take turns clicking on the board to make your moves
4. After a game ends, you can request a rematch
