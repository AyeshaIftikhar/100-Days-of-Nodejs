# 1) Create the project folder and files as below (copy-paste the code blocks)
# 2) Install dependencies
```
npm install
```

# 3) Link the CLI (global command `clivault`)
```
npm run link
```

# 4) Initialize a new vault (sets master password)
```
clivault init
```

# 5) Add a password
```
clivault add
```

# 6) List entries
```
clivault list
```

# 7) Retrieve a password (optionally copy to clipboard)
```
clivault get <service> [username] --copy
```
